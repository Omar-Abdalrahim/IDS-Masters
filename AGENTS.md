# Repository instructions

This repository is part of Masters_Omar.

## Document every change

- Before editing, retrieve/read the current root `README.md` and preserve its existing change-history entries.
- For every repository change, prepend a new entry under `## Change history` in that README.
- Record the actual change date and time in `Africa/Cairo`, including its UTC offset. Do not reuse a timestamp from an earlier entry.
- List the exact affected notebook paths. For a change with no notebook edits, write `Notebook: none`. Also list other affected files.
- Under the entry, explain the changes, why they were made, validation performed, and material limitations or rerun instructions.
- Include the updated README in the same commit as the implementation. Use a descriptive commit message.
- Do not invent completed runs or test results. Keep older entries intact; use Git history for versions before written logging began.
